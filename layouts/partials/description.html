• Generic

    The unmodified, original build of BlissOS

    This is the version most people are looking for. It provides a BlissOS build suitable for nearly all hardware, combine with a LTS kernel for a stable experience.

  • Surface

    Designed specifically for the Microsoft Surface devices

    This version is designed specifically for the Microsoft Surface devices. The kernel use almost the same LTS kernel but with extra patches from the linux-surface project to ensure the most compatibility.

  • Go

    Designed specifically for the low-end hardware

    This version is designed specifically for the low-end hardware. While using the same LTS kernel as the Generic variant, we've added a few tweaks to the internal Android parts to make sure you can have a good experience even if your hardware is limited.

  • Zenith

    The new flagship build of BlissOS

    Zenith is a new BlissOS variant that is intended for "chasing the latest". We will build this variant with only the latest version of BlissOS that is available, combine with latest Stable kernel. BlissOS is intended for people who are having a new hardware that LTS kernel can't support, or people who just want to "chasing the latest".
