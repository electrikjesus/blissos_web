BlissOS Website - Configuration Guide
=====================================

Project Configuration Files
---------------------------

package.json
------------
Main Node.js configuration file containing:

Dependencies:
- express: Web server framework
- ejs: Templating engine
- @splidejs/splide: Carousel/slider component

Development Dependencies:
- nodemon: Auto-restart server during development
- concurrently: Run multiple npm scripts simultaneously
- tailwindcss: CSS framework
- @tailwindcss/typography: Typography plugin for Tailwind
- autoprefixer: CSS vendor prefix automation
- postcss: CSS processing tool
- postcss-cli: PostCSS command line interface
- alpinejs: Lightweight JavaScript framework

Scripts Configuration:
start: "concurrently \"npm run watch:css\" \"npm run dev\""
dev: "nodemon server.js"
watch:css: "tailwindcss -i ./assets/css/main.css -o ./assets/css/style.css --watch"
build:css: "tailwindcss -i ./assets/css/main.css -o ./assets/css/style.css --minify"
build: "npm run build:css && node server.js"
production: "NODE_ENV=production node server.js"

tailwind.config.js
------------------
Tailwind CSS configuration:

Content Sources:
- "./views/**/*.ejs" - EJS template files
- "./assets/**/*.js" - JavaScript files

Dark Mode: "class" - Uses class-based dark mode switching

Theme Extensions:
- Custom color scheme (primary, secondary, neutral)
- Extended line heights
- Typography plugin configuration with custom prose styles
- Dark mode prose styles for better readability

Typography Colors:
- Light mode: Zinc color palette
- Dark mode: Inverted colors with indigo accents
- Code highlighting: Indigo theme

server.js
---------
Express.js server configuration:

Port Configuration:
- Default: 3010
- Environment variable: PORT
- Fallback: process.env.PORT || 3010

View Engine:
- Engine: EJS
- Views directory: ./views
- Partials support: <%- include('partials/filename') %>

Static File Serving:
- /assets route serves ./assets directory
- Includes CSS, JavaScript, images, and other static files

Routes:
- GET / - Homepage (renders index.ejs)
- GET /licensing - Licensing page (renders licensing.ejs)

Template Variables:
- title: Page title for <title> tag
- description: Meta description for SEO

postcss.config.js
-----------------
PostCSS configuration for CSS processing:

Plugins:
- tailwindcss: Main Tailwind CSS processing
- autoprefixer: Automatic vendor prefixes

Environment Variables
--------------------

Development:
NODE_ENV=development (default)
PORT=3010 (default)

Production:
NODE_ENV=production
PORT=3010 (or server-specific port)

Setting Environment Variables:

Windows:
set NODE_ENV=production
set PORT=8080
npm start

Unix/Linux/Mac:
export NODE_ENV=production
export PORT=8080
npm start

Or inline:
NODE_ENV=production PORT=8080 npm start

CSS Configuration
-----------------

Input File: assets/css/main.css
- Contains Tailwind directives
- @tailwind base;
- @tailwind components;
- @tailwind utilities;
- Custom CSS can be added here

Output File: assets/css/style.css
- Generated by Tailwind CSS
- Minified in production builds
- Should not be edited manually
- Excluded from Git via .gitignore

Additional CSS Files:
- assets/css/splide-sea-green.css: Splide carousel styling
- assets/css/dlstyle.scss: Download section styles (legacy)
- assets/css/indexStyle.scss: Homepage styles (legacy)

JavaScript Configuration
------------------------

Alpine.js:
- Loaded from assets/js/alpine.js
- Provides reactive components
- Used for navigation menu toggle
- Dark mode functionality

Custom Scripts:
- assets/js/darkmode.js: Dark/light mode switching
- assets/js/splide.js: Carousel/slider functionality
- assets/js/cookies.js: Cookie handling (if needed)

External Dependencies:
- FontAwesome: Loaded via CDN
- Kit ID: bc56c2b7b7

Template Configuration
---------------------

EJS Templates:
- No layout system (full HTML in each template)
- Partials for reusable components
- Template variables passed from routes

Partials:
- views/partials/nav.ejs: Navigation component
- views/partials/footer.ejs: Footer component

Template Variables:
- title: String for page title
- description: String for meta description

Asset Paths:
- Static assets: /assets/path/to/file
- Images: /assets/images/filename
- CSS: /assets/css/filename
- JavaScript: /assets/js/filename

Development Configuration
------------------------

Hot Reloading:
- CSS: Automatic rebuild on file changes
- Server: Automatic restart via nodemon
- Templates: Server restart triggers browser refresh

Watch Patterns:
- Tailwind: Watches views/**/*.ejs and assets/**/*.js
- Nodemon: Watches server.js and views/**/*

Build Process:
1. Tailwind processes main.css
2. Outputs to style.css
3. Express serves static files
4. EJS renders templates

Production Configuration
-----------------------

Optimizations:
- NODE_ENV=production enables Express optimizations
- CSS minification via --minify flag
- Static file caching headers
- Gzip compression (via reverse proxy)

Security:
- No sensitive data in client-side code
- Environment variables for configuration
- Static file serving with proper headers

Performance:
- Minified CSS
- Optimized images
- CDN for external resources
- Efficient Express middleware

Customization Options
--------------------

Adding New Pages:
1. Create EJS template in views/
2. Add route in server.js
3. Update navigation if needed

Modifying Styles:
1. Edit Tailwind classes in templates
2. Add custom CSS to main.css if needed
3. Rebuild with npm run build:css

Adding JavaScript:
1. Create JS file in assets/js/
2. Include in template or footer partial
3. Ensure proper loading order

Changing Port:
1. Set PORT environment variable
2. Update any hardcoded references
3. Update documentation

Theme Customization:
1. Modify tailwind.config.js
2. Update color schemes
3. Rebuild CSS
4. Test dark mode compatibility

Troubleshooting Configuration
----------------------------

CSS Not Loading:
- Check Tailwind build process
- Verify file paths in templates
- Ensure style.css is generated

JavaScript Errors:
- Check browser console
- Verify file paths
- Check for syntax errors

Server Won't Start:
- Check port availability
- Verify Node.js version
- Check for syntax errors in server.js

Environment Issues:
- Verify environment variables
- Check NODE_ENV setting
- Confirm all dependencies installed

Template Errors:
- Check EJS syntax
- Verify partial paths
- Ensure template variables are passed
